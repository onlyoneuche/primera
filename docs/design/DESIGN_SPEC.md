# Interface design specification

No reference images have been supplied. Use BUILD_SPEC section 9.3's Daybreak direction in Phase 3. Phase 2 established the accessible flow. The first Phase 3 implementation now applies the Daybreak specification below and awaits owner visual review.

## Flow and layout

Welcome → nine required questions → at least 400 ms loading → lower/higher result. Use one column, approximately 560 px wide, with the same flow at 390×844 and 1280×800. Include question text, textual/visual progress, specific errors, native faculty selection, age input, radio choices, a CGPA scale toggle, and back navigation. Keep supporting copy below the main action. Results include support resources, limitations, a disclaimer, and restart. How this works opens a keyboard-accessible modal.

## Implemented Daybreak styling

Palette: ink #17324D, secondary #4B6277, background #F4FAF8, white cards, primary #0B7A5E, bright accent #12B886, sun #FFC83D, coral illustration accent #FF7F6B, sky #8EC9FF, lilac #B8A9FF, line #D6E8E1. Higher risk: #FFF1CC with #5A3E00. Lower risk: #D5F3E6 with #0B4D3B. Focus #1F6FEB; inline errors #B4430B. Risk is always stated in words; never use red or celebratory visuals.

Self-host Bricolage Grotesque 700/800 for headings and Figtree 400/600 for body copy; use font-display swap with system fallbacks. Type scale: 14, 16, 18, 22, 28, 36, 48 px. Body 17–18 px, line-height 1.55; headings 1.15; lines under 62 characters.

Use an 8 px spacing scale. Cards: 24 px radius; option tiles: 18 px; inputs: 14 px; pill buttons. Use large soft primary-tinted shadows. Selected tiles have a primary border, soft sun tint, and an explicit check. Controls have 48 px minimum touch targets and visible 3 px focus outlines.

Welcome: original rising-sun/rolling-hills SVG and a restrained sky-to-mint backdrop with static sun, sky, and lilac shapes. Support: original overlapping speech bubbles. Lower result: calm sun/leaf. Higher result: warm lantern/open hand. Each SVG under 8 KB; no faces or third-party artwork. The small Phase 2 favicon is an original two-circle mark.

Motion: one welcome entrance, 150 ms selection response, 200 ms question transitions, 400 ms result reveal. Disable all animation under reduced motion. Use a segmented progress path with a sun marker in Phase 3. No loops.
